# Email Validation

## Описание проекта

Небольшое веб-приложение с формой для ввода email-адреса и кнопкой «Проверить».

Валидация выполняется только после нажатия кнопки «Проверить».


## Тест-кейсы

### Блок 1. Валидные email-адреса

#### TC-01. Ввод корректного адреса электронной почты

**Шаги:**

1. Ввести в поле `k@academy.ru`.
2. Нажать кнопку «Проверить».

**Ожидаемый результат:**

Появилось оповещение с текстом «Отличный email-адрес».

---

### Блок 4. Поведение валидации

#### TC-12. Отсутствие валидации при вводе email

**Шаги:**

1. Кликнуть в поле email.
2. Ввести `test`.
3. Не нажимать кнопку «Проверить».

**Ожидаемый результат:**

Валидация не выполняется. Сообщение об ошибке не появляется.
